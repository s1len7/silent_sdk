# 사용자에게 명령 실행 부탁

## 규칙

- 사용자 입력이 필요한 명령(비밀번호, 로그인, y/n 확인, 대화형 프로그램)은 어떤 상황에서도 `!` 형태로 주지 말 것
  - `!` 명령은 에이전트 셸에서 실행돼 터미널(tty)이 없으므로 입력을 받지 못함
  - 확인 사례: `ssh -t <장비> "sudo ..."`가 `Pseudo-terminal will not be allocated because stdin is not a terminal`을 내고 sudo가 비밀번호를 묻지 못함
- `!`는 입력 없이 끝나는 명령에만 쓸 것
- 자동 모드는 도구 호출 승인만 생략함. 비밀번호·로그인은 대신 해 주지 않음
- 권한 확인(sudo 비밀번호 등)을 다른 경로로 우회하지 말 것

## 절차

1. 먼저 입력 없이 되는지 확인할 것 (예: 원격 sudo는 `ssh <장비> 'sudo -n true'`, `sudo: a password is required`면 불가)
2. 사용자 없이 할 수 있는 확인·시험·준비를 모두 끝낼 것
   - 원격 장비에 올릴 스크립트는 `scp`로 `/tmp/<작업>/`에 복사 (장비 저장소 작업 트리는 건드리지 않음)
3. 사용자에게는 **별도 터미널**에서 실행할 명령 한 줄만 줄 것
   - 끝나면 "끝났다"고만 알려 달라고 할 것 (출력을 붙여 달라고 하지 않음)
4. 결과는 에이전트가 입력 없이 직접 확인할 것 (예: `systemctl is-enabled`, 설치 파일, `journalctl -u <서비스>`)
5. 확인이 끝나면 임시 파일(`/tmp/<작업>/` 등)을 지울 것
