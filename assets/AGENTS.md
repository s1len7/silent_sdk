# assets 규칙

- 장비/스크립트에서 공통으로 사용하는 정적 자산을 저장함
- 자산을 추가하거나 사용할 때는 **반드시 라이선스를 확인**할 것 (특히 폰트)
- 파일명은 소문자 영문과 하이픈(`-`)만 사용, 공백과 한글 금지
- 파일 크기는 가능한 작게 유지할 것. 가능하면 오픈 형식(.svg, .webp, .ogg) 사용
- 최상위 디렉토리마다 `.gitkeep`을 둘 것
- 새 최상위 디렉토리를 만들 때는 `.gitkeep`을 추가할 것
- 자산마다 라이선스가 다르면 `LICENSES/`에 정리할 것
- 라이선스가 다른 자산이 있으면 `LICENSES/`에 정리할 것
- 라이선스가 불확실하면 커밋하지 말 것
- 자산 추가/사용 전 반드시 라이선스를 확인할 것
- 파일은 작게 유지하고, 가능한 웹 친화적 형식을 사용할 것
