# assets

장비/스크립트에서 공통으로 사용하는 정적 자산(아이콘, 오디오, 폰트, UI 요소)

## 구조
- `icons/` - 아이콘
- `audio/` - 효과음/알림음
- `fonts/` - 폰트 (사용 전 반드시 라이선스 확인)
- `ui/` - UI 요소/이미지

## 참고
- 자산 추가/사용 전 반드시 라이선스를 확인할 것
- 파일은 작게 유지하고, 가능한 웹 친화적 형식을 사용할 것
- 새 최상위 디렉토리를 만들 때는 `.gitkeep`을 추가할 것
- 라이선스가 다른 자산이 있으면 `LICENSES/`에 정리할 것
